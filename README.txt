CAD & MANUFACTURING ADVANCED WEBSITE

Files
-----
index.html       Public website + lead form
admin.html       Local demo lead dashboard
styles.css       Responsive dark engineering theme
app.js           Lead form + WhatsApp logic

QUICK START
-----------
1. Open index.html in a browser.
2. Replace 91XXXXXXXXXX in app.js with your WhatsApp number.
3. Replace any portfolio placeholders with your real work.
4. Test the form.
5. Open admin.html to see demo leads.

IMPORTANT
---------
This version is a FRONT-END DEMO. Leads are stored in the browser's localStorage.
The uploaded file is NOT sent to a server. Only its filename is recorded.

For a real business website, connect:
- Supabase or Firebase for lead database
- Cloud storage for CAD/PDF uploads
- Email notifications
- Admin login/authentication
- HTTPS/domain
- Spam protection
- Privacy/consent checkbox

Recommended production flow:
Instagram -> Website -> Lead form -> Database -> Email/WhatsApp notification -> Admin dashboard -> Quote.
